## 1. Context & Motivation

To enable parallel execution across Wave 2 mobile UI lanes (WP-11 Briefing & Evidence, WP-12 Evidence Board, WP-13 Theory & Reveal), the case screen navigation route and slot data contracts must be strictly decoupled from feature implementations. UI components must never directly import `LocalGameService`, raw `CaseDefinition`, or engine scoring functions. All state and actions must flow through a centralized, type-safe hook contract.

## 3. The `useCaseSession` Hook Contract

Exported from `apps/mobile/src/features/case/slots.ts` (implemented in `apps/mobile/src/store/`):

```ts
export type CaseSessionStatus = 'loading' | 'active' | 'submitted' | 'error';

export interface UseCaseSessionReturn {
  casePublic: CasePublic | undefined;
  session: SessionState | undefined;
  status: CaseSessionStatus;
  error?: GameServiceError;
  result?: ScoreResult;
  reveal?: Reveal;
  unlockClue: (clueId: string, via: ClueUnlock) => Promise<void>;
  saveBoard: (board: BoardState) => void;
  markClueRead: (clueId: string) => void;
  submit: (submission: Omit<Submission, 'sessionId'> | Submission) => Promise<void>;
}

export function useCaseSession(sessionId: string): UseCaseSessionReturn;
export function useGameService(): GameService;
```

### Behavior Guarantees:

1. **`casePublic`**: Holds the redacting allow-list view (`CasePublic`). Locked clues contain only `{ id, type, locked: true, hint }`.
2. **`unlockClue(clueId, via)`**: Unlocks a clue through `GameService.unlockClue`. Updates `casePublic.clues` and removes `clueId` from `lockedClueIds`.
3. **`saveBoard(board)`**: Optimistically updates the Zustand session store immediately, then debounces the call to `GameService.saveBoard` by **500ms**.
4. **`markClueRead(clueId)`**: Tracks unread clues locally per session.
5. **`submit(submission)`**: Idempotent. Flushes any pending debounced `saveBoard`, submits to `GameService.submit`, updates status to `'submitted'`, and populates `result` and `reveal`. Double-submitting or submitting while a request is in flight is a guaranteed no-op.
6. **`status`**: State machine indicator (`'loading' | 'active' | 'submitted' | 'error'`). When `status === 'submitted'`, the root case screen switches tab to `reveal`.

## 5. Security & Isolation Invariant

- `CaseDefinition` is never stored or exported outside `LocalGameService`.
- UI features (WP-11/12/13/23/24) interact exclusively through `useCaseSession` and `useGameService`.
- All data returned to the UI is validated against `deepScan` to ensure no sensitive fields (`truth`, `claims`, `culpritIds`, `seed`, `keyEvidence`, `liars`, hidden text) are ever exposed.
