# Proposal WP-30: Wiring renderClue into Validator Check V11

> Author: Agent A2 (Lane E: Engine, WP-30)  
> Date: 2026-10-29  
> Target: Integrator / Validator Enhancement (Wave 2 / WP-31)  

---

## 1. Background

In `packages/case-engine/src/validator/checks/v11_text_render.ts`, check V11 currently verifies static clue text:
```ts
if (!clue.text || clue.text.trim().length === 0) {
  issues.push({
    checkId: 'text.render',
    severity: 'error',
    message: `Clue '${clue.id}' renders to empty or whitespace-only text`,
    refs: [clue.id],
  });
  continue;
}
```

With the delivery of **WP-30** (`packages/case-engine/src/render/`), the engine now has a deterministic, seeded clue and fact renderer:
- `buildRenderWorld(def: CaseDefinition): RenderWorld`
- `renderClue(clue: Clue, world: RenderWorld, rng: Rng): string`

---

## 2. Proposal

We propose updating `v11TextRenderCheck` in a future task (or integrator wave) to utilize `renderClue` when evaluating clue text:

### 2.1 Dynamic Clue Text Evaluation
If `clue.text` is omitted or empty (as will be standard for procedural cases generated from templates in WP-31–WP-34), V11 should:
1. Build `world = buildRenderWorld(def)`.
2. Seed an RNG using `def.meta?.seed ?? 0`.
3. Compute `effectiveText = renderClue(clue, world, rng)`.
4. Validate that `effectiveText` is non-empty and contains no unresolved template variables `{{...}}`.

### 2.2 Content Guard Enforcement (SYSTEM_DESIGN §3.6)
V11 should verify that `effectiveText`:
1. Only references character names that appear in `clue.asserts` or `clue.source`.
2. Only references time strings (`HH:MM`) that are asserted within `clue.asserts`.
3. Does not leak internal IDs (such as `def.truth.solutionHypothesisId`).

### 2.3 Proposed Implementation Sketch
```ts
import { buildRenderWorld, renderClue } from '../../render/index.js';
import { createRng } from '../../rng.js';

export const v11TextRenderCheck: ValidatorCheck = {
  checkId: 'text.render',
  run(def: CaseDefinition, _ctx: ValidatorContext): ValidationIssue[] {
    const issues: ValidationIssue[] = [];
    const world = buildRenderWorld(def);
    const rng = createRng(def.meta?.seed ?? 0);

    for (const clue of def.clues) {
      const text = renderClue(clue, world, rng);
      if (!text || text.trim().length === 0) {
        issues.push({
          checkId: 'text.render',
          severity: 'error',
          message: `Clue '${clue.id}' renders to empty or whitespace-only text`,
          refs: [clue.id],
        });
        continue;
      }

      // Check template variables and leak guards on text...
    }

    // Validate reveal beats...
    return issues;
  },
};
```
