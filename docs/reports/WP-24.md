# WP-24 Report: Home & Library

## Summary
- **Dominant "Solve a Case" Hero CTA**: Built a responsive, high-contrast hero CTA that uses the pure `selectNextCase` engine to route the player directly into the optimal next case.
- **Pure Selection Engine (`selectNextCase.ts`)**: Picks the next unplayed case closest to the player's level (matching rank difficulty, or ascending unplayed cases), and falls back gracefully to suggesting highest-rated/unplayed replay archive cases when all available cases have been solved.
- **Active Case "Continue Investigation" Card**: Dynamically displays any in-progress investigation session with relative time/progress info, allowing seamless resumption with a single tap.
- **Daily Case Slot & Cyberpunk Operational Logs**: Implemented a locked/preview daily case card slot with countdown badge, accompanied by atmospheric Vesper City dispatch/ticker logs.
- **Pure Filter Logic & Case Catalog (`catalog.ts`, `filterCases.ts`)**: Case catalog with metadata across difficulties and crime types (`missing_item`, `theft`, `murder`, `forged_message`). Pure filtering by difficulty chip, mystery type chip, solve status (All / Solved / Unsolved), and real-time text search.
- **Investigate Library Slot & Badges**: Clean FlashList-ready case catalog display featuring status badges (`SOLVED` / `UNSOLVED` / `IN PROGRESS`), difficulty dots, solve stats, and immediate launch handlers.
