## Decisions Made

1. **Unambiguous Code Normalization**: In addition to validating raw 8-character codes, `validateChallengeCode` automatically extracts the code from full URLs or route paths (e.g. `https://thelastlie.game/c/8X99K2LP` or `/c/8x99k2lp`), converts to uppercase, and validates the unambiguous alphabet to provide forgiving deep-link ingestion.
2. **Local Mode Challenge Fallback**: When playing in offline/local mode without an active backend connection, the reveal screen generates a deterministic local challenge code `#CHXXXXXX` derived from the session ID, ensuring the UI flow remains testable and functional offline.
3. **Guest Token Persistence Keying**: Guest tokens are persisted in `KeyValueStore` under `@lastlie/guest_token_${code}`, ensuring a player re-opening the same challenge link in the browser preserves their in-flight guest token and session state.
