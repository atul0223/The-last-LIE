# WP-50/55 — Daily & Weekly UI Integration Report

## 1. Summary
- **Home Daily Card & Streak Engine**: Implemented `computeDailyStreak` in `apps/mobile/src/features/home/streak.ts` tracking daily solve streaks across consecutive calendar days. Follows the streak grace invariant: missing a day resets the active streak counter to 0 upon next solve, but **NEVER** deducts XP, player mastery score, detective rank, or unlocked dossiers.
- **Deterministic Local Daily Mystery**: Enhanced `LocalGameService.getDaily()` to deterministically select a daily mystery from bundled cases by hashing the UTC date string (`YYYY-MM-DD`). Offline players and players without remote backend access see the identical mystery on any given calendar day.
- **Weekly Community Dispatch Section**: Implemented `WeeklySection` and `useWeekly` in `apps/mobile/src/features/challenges/` and integrated into `apps/mobile/app/(tabs)/challenges.tsx`.
  - **Open Window State**: Shows live countdown timer (`⏱ {days}D {hours}H REMAINING`), case title, briefing, rules notice (only first attempt counts), and CTA (`PARTICIPATE IN WEEKLY CASE`). Official leaderboard and theory distributions remain strictly classified.
  - **Closed Window State**: Unlocks final community standings, total participants, average score, leaderboard rows (rank, callsign, score), and community theory hypothesis distribution percentage bars.
- **Security & Privacy**: Verified via `deepScan` tests that no sensitive leak keys (`truth`, `culpritIds`, `liars`, `claims`, `seed`, `keyEvidence`, `solutionHypothesisId`) are present in daily/weekly responses or UI renders.

## 5. Decisions Made
1. **UTC Date String Hashing**: Used a 32-bit integer polynomial rolling hash `(hash * 31 + charCode) >>> 0` on UTC date `YYYY-MM-DD` modulo the sorted catalog length. This produces deterministic, uniform distribution without needing external crypto or RNG seed dependencies.
2. **Graceful Offline Local Fallback for Weekly**: When `RemoteGameService` or backend API is unavailable (offline local mode), `useWeekly` generates a synthetic local weekly window using canonical case 0001 with 7-day schedule, allowing players to play weekly duels seamlessly even without network connectivity.
3. **Pre-interpolated JSX Strings**: Used template literals (`{`#${rank}`}`, `{`${score} PTS`}`) to prevent `react-test-renderer` from fragmenting text strings into split child arrays, ensuring robust snapshot and a11y testing.
