- Implemented `fingerprint(def: CaseDefinition): string`, extracting normalized templateId, culprit roles (not character names), decisive contradiction ruleId, sorted location IDs, liar count, and sorted keyEvidence clue types, hashed via pure deterministic `cyrb128`.

## 5. Decisions Made

1. **Pure Deterministic Hashing**: Used `cyrb128` (matching PRNG implementation in `rng.ts`) without any Node.js `crypto` or platform APIs to maintain complete determinism and portability across browser, server, and CLI.
2. **Decisive Rule Resolution**: Checked reveal explanation beats first to identify the specific contradiction refuting the declared liar statement, falling back to keyEvidence contradiction checks.
3. **Difficulty Calibration Scaffolding**: Structured calibration into `tools/cli/src/report/calibration.ts` so `packages/case-engine/src/validator/config.ts` was not modified, preserving frozen weights pending real playtest data.
