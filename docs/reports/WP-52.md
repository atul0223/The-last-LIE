Revealed nodes display kind badge, full name, public summary, and confirmed corridors; unrevealed nodes display encrypted lead warnings and investigation prompts.
- **Accessible List View Alternative**: Built `ConspiracyListView` (`testID="conspiracy.list.container"`) providing a screen-reader-friendly alternative to the 2D canvas, grouping revealed nodes by kind and listing unknown network leads.

## 5. Decisions Made
1. **Topology-Signature Layout Caching**: Keyed layout cache by canvas dimensions and sorted node/edge IDs. Layout is calculated exactly once on initial reveal and cached in-memory, preserving layout stability across tab switches and re-renders.
2. **Strict Anonymization of Neighbor Leads**: To prevent plot spoilers, unrevealed 1-hop neighbor nodes construct a sanitized `MapNode` object where `name: '?'`, `kind: 'unknown'`, and the public summary contains generic classified text. The real node names are omitted entirely from unrevealed data structures.
3. **Web / Test Non-Skia Fallback**: Checked `typeof Canvas !== 'undefined' && Platform.OS !== 'web'` in `ConspiracyCanvas` to seamlessly render fallback DOM/View elements on web and in headless test runners without breaking Skia native bindings on iOS/Android.
