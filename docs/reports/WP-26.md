## 1. Summary

- Updated `LocalGameService` to safely load `GENERATED_CASES` from `@lastlie/content` with a fallback to `[]` if the export is absent on main, plus constructor options allowing injection of generated cases without direct file imports.
- Updated `CASE_CATALOG` and catalog utilities to represent both authored and generated cases (`kind: 'authored' | 'generated'`), adding `caseDefinitionToCatalogItem` and `getCaseCatalog`.
- Enhanced `LibraryFeature` with a distinct `⚙ GENERATED` badge (`case.badge.generated.<caseId>`) and an origin filter (`ALL SOURCES`, `AUTHORED`, `GENERATED` with `library.filter.origin.<origin>`).
- Updated `selectNextCase` home selection logic to strictly prefer unplayed **AUTHORED** cases first (ordered by closeness to player level), and only fall back to unplayed **GENERATED** cases at player level once all authored cases are solved.
- Added comprehensive unit and security tests in `apps/mobile/tests/generated_library.test.tsx`, including a strict `deepScan` test verifying that generated cases served via `LocalGameService` never leak private solution fields (`truth`, `claims`, `culpritIds`, `seed`, `asserts`, `keyEvidence`, `liars`, `conspiracyHooks`, `red_herring`) or locked clue contents.
